# Project Scope

## Problem

The project improves PMIS allocation by addressing role mismatch, lack of allocation explanation, fairness visibility, dry-run allocation, waitlist recovery, company-side fulfillment and operational edge cases.

## MVP

- Student profile and eligibility
- Internship listings
- Preference submission
- Pairwise preference elicitation
- Company listing management
- Eligibility and compatibility scoring
- Stable matching + OR-Tools policy reconciliation
- Budget ceiling constraint
- Simulation sandbox
- Human approval
- Allocation explanation
- Counterfactual explanation
- Waitlist and incremental reallocation
- Fairness dashboard
- Exception queue
- Audit log with hash chain
- Seeded demo data

## Demo differentiator

Admin selects a synthetic student, changes one preference or skill, runs a live replay, and sees the allocation and explanation change.

## Production roadmap

- Shadow-mode rollout
- Government identity/eKYC adapters
- DBT adapter
- DigiLocker certificate adapter
- UMANG distribution adapter
- MCoC-aware scheduler
- Offline/manual identity verification path
- SMS/USSD adapters
- Full ML training and monitoring
- Empanelled cloud deployment
