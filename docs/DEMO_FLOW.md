# SIH Demo Flow

## 1. Student

Show:
- profile
- skill normalization
- pairwise preference elicitation
- ranked preference result

## 2. Admin

Show:
- cycle dashboard
- supply and demand
- fairness metrics
- budget headroom
- simulation configuration

## 3. Simulation

Run:
- baseline
- increased aspirational-district quota
- compare outcomes

Show:
- allocation rate
- preference satisfaction
- fairness delta
- unallocated students
- budget usage

## 4. Approval

Admin reviews:
- constraint trace
- exceptions
- solver status
- audit hash

Click approve.

## 5. Student explanation

Show:
- assigned company
- preference rank
- skill matches
- capacity effect
- policy effect

Then show counterfactual:
"Adding Basic SQL would have moved you above the cutoff for choice #1."

## 6. Live replay

Judge changes one skill or preference.

Re-run the synthetic case and display the changed result.

## 7. Edge case

Trigger a company withdrawal.

Show:
- affected allocation
- waitlist promotion
- notification
- audit event
